# Source notes

These are the intended source families for the RRLANG corpus pack.

## UDHR

- OHCHR translation pages: official UN Human Rights translation pages in HTML/PDF.
- EFELE / UDHR-in-XML: plain text/XML conversions designed to disseminate UDHR translations.
- Unicode UDHR historical project: useful because it established the Unicode/plain-text approach, though availability has shifted over time.

## FLORES-200

FLORES-200 is a professionally translated benchmark released by Meta/Facebook Research under CC-BY-SA 4.0. It has dev/devtest splits and around 3001 sentences across 842 source web articles.

## Tatoeba

Tatoeba sentence downloads are CC BY 2.0 FR; attribution is required. Use later for short conversational sentence rhythm.

## OPUS

OPUS is a very large open parallel corpus family. It is valuable but license-mixed. Use later, only with per-corpus license checks.
